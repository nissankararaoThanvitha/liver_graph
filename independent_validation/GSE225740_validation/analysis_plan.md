# Fixed-shortlist external-cohort replication plan

Recorded before executing the validation script, 7 November 2026. The cohort was chosen on metadata, gene coverage and recruitment provenance, not association results. No independent-registration timestamp is claimed.

- Input: GSE225740, 87 observed staged patients; all 23 fixed genes in the existing Paper 1 shortlist, original order, IDs, directions and cluster membership retained. Missing-stage samples excluded; no gene selection, reclustering, reranking or expression-based sample exclusion.
- Primary analysis: two-sided SciPy Spearman association between each gene's log2(CPM+1) and numerical F0–F4 stage. The deposited stage is a cross-sectional severity measure, not longitudinal progression. Standardization is unnecessary for Spearman because it is an increasing linear transform per gene.
- Primary multiple-testing family: exactly 23 hypotheses, Benjamini–Hochberg adjustment. Concordant replication is defined as q<0.05 and matching the sign of the original median-study rho. Report same-direction nonsignificant, opposite-direction nonsignificant and opposite-direction significant results separately. No requirement of rho>=0.30 is added to the validation decision.
- Sensitivity: 9,999 random patient-label permutations, fixed seed 20261107; identical shuffled labels used across all genes. Two-sided absolute rho, plus-one Monte Carlo p=(1+extreme)/(10000), BH over 23 permutation p values. This is an unadjusted association sensitivity check, not covariate-controlled analysis or a second chance to define replication.
- Uncertainty: 2,000 within-stage patient bootstrap resamples, seed 20261108, percentile 95% rho intervals. These intervals are conditional on the observed stage counts, are pointwise (not simultaneous), and do not replace primary BH-adjusted p values.
- Pattern assessment: display all 23 stage-mean profiles next to their frozen original profiles. For comparable shape display, independently centre and scale each five-stage mean vector using SD ddof=0. This is a descriptive comparison of five stage means, not reclustering, a statistical test of shape equivalence, or evidence of individual trajectories. Save original and validation unscaled values too.
- Low expression: HTR7 and CACNA1C were flagged before testing and remain included. Report availability for every gene. F4 has six patients, so late-stage means have limited precision. No later-stage covariate adjustment is promised: the deposited phenotype file supplies NAS, fibrosis and steatohepatitis, not individual age/sex/BMI. No drug or causal effects are tested.
- Independence: distinct-cohort recruitment is supported with no shared GSM; individual donor non-overlap is not verified. See the prior cohort-independence audit.
- Preserve all scientific outcomes, including discordant genes. Do not overwrite discovery files, graph, manuscript or published release. Hash inputs and save the complete 23-gene table and vector PDF figures.
